# 🌙 ClyrApp — Clarity & Recovery Tracker

ClyrApp adalah aplikasi personal berbasis web yang dirancang untuk membantu pengguna mengurangi kecanduan konten negatif (seperti pornografi) melalui pendekatan **monitoring**, **self-journaling**, **habit tracking**, dan **pemantauan waktu penggunaan**.

Aplikasi ini dibuat dengan **Vue 3 + Vite**, menggunakan **Supabase Authentication** sebagai sistem login/daftar, serta sistem UI yang clean untuk memberikan pengalaman penggunaan yang nyaman dan fokus.
